# Story 3.4: Sincronização da página Lotofácil com fallback local

**Status:** Done
**Epic:** 3 — CAIXA e laboratório
**Fonte:** [PRD — FR-03, NFR-03, NFR-07](../prd.md)

## Decisão de reutilização

Reutilizar o contrato HTTP com timeout e a persistência 3.1/3.3; criar um parser
JSON versionado e específico para o resultado mais recente; restringir a coleta
à URL exata autorizada no domínio oficial da CAIXA. Catálogo, histórico,
automação de navegador e qualquer outro endpoint não documentado continuam fora
do escopo.

## Critérios de aceite

1. A coleta automática do resultado mais recente usa exclusivamente
`https://servicebus2.caixa.gov.br/portaldeloterias/api/lotofacil`. (FR-03)
2. O parser exige `tipoJogo` igual a `LOTOFACIL`, concurso inteiro positivo,
data `dd/mm/aaaa` e exatamente 15 dezenas únicas entre 01 e 25. Resposta válida
usa o fluxo 3.3; resposta recebida mas inválida fica auditável sem snapshot.
(FR-03, NFR-03)
3. Falha de transporte retorna o último snapshot válido e não o altera. (FR-03,
NFR-03)
4. Testes cobrem payload válido e inválido, URL fixa, erro HTTP, timeout e falha
de transporte sem rede real. (NFR-07)
5. Não há outro endpoint não documentado, automação de navegador, catálogo,
histórico, estratégia, geração ou UI.

## Dev Agent Record

- A sincronização automática usa somente a URL JSON exata autorizada no domínio
  oficial; a importação HTML local continua separada como contingência.
- Falha de transporte retorna `FAILED` com o último snapshot válido; conteúdo
  recebido mas inválido é auditado como `INVALID`; conteúdo válido cria snapshot.
- O coletor aborta e rejeita chamadas que excedem 10 segundos; o limite também
  permanece ativo durante a leitura do corpo da resposta.
- Falha de coleta retorna JSON com fallback e código 1; falha de persistência não
  é registrada como conteúdo `INVALID`.
- O contrato reutiliza transporte com timeout e persistência; o parser JSON
  `lotofacil-caixa-result-json/1` valida modalidade, concurso, data e quinze
  dezenas únicas entre 01 e 25.
- Prova ponta a ponta real persistiu o concurso 3774 como `VALIDATED` em banco
  temporário, sem alterar dados do projeto.
- PASS: lint, typecheck, 91 testes e `git diff --check`.
- PASS: CodeRabbit local, 0 achados em `packages/result-ingestion` e `apps/cli`.
